# IT Infrastructure & Cyber Security Home Lab Portfolio

Selamat datang di repositori portofolio praktik saya! Repositori ini berisi dokumentasi teknis (*technical write-ups*) dari berbagai simulasi laboratorium virtual (*Home Lab*) yang saya bangun untuk mengasah keterampilan di bidang **IT Infrastructure**, **System Administration**, dan **Cyber Security** (mencakup sisi *Blue Team* maupun *Red Team*).

---

## 🛠️ Keterampilan & Perangkat Lunak (Tools & Technologies)
* **Sistem Operasi:** Ubuntu Server LTS, Kali Linux, Windows Server 2022, Windows 11
* **Virtualisasi & Jaringan:** Oracle VirtualBox, Cisco Packet Tracer, TCP/IP, Subnetting, SSH, DNS, DHCP
* **Keamanan Sistem & Jaringan (Blue Team):** UFW Firewall, SSH Key Hardening, Log Forensics (`/var/log/auth.log`), Active Directory & IAM
* **Pengujian Keamanan (Red Team):** Nmap (Network Scanning), Hydra (Brute Force Testing)
